# MCP Resume

| **Category**  | **Controlled By** | **Purpose**                    | **How It Works**                                                 | **Typical Use Cases**                                | **Example**                             |
| ------------- | ----------------- | ------------------------------ | ---------------------------------------------------------------- | ---------------------------------------------------- | --------------------------------------- |
| **Tools**     | Model (AI)        | Extend the AI’s capabilities   | The AI decides when to call tools and uses results automatically | Calculations, code execution, API calls, automation  | AI runs JavaScript to calculate √3      |
| **Resources** | Application       | Provide data for UI or context | App fetches and injects data into UI or prompts                  | Autocomplete, document retrieval, context enrichment | “Add from Google Drive” content loading |
| **Prompts**   | User              | Trigger predefined workflows   | User manually activates workflows via UI                         | Reusable tasks, guided workflows, quick actions      | Workflow buttons or slash commands      |

## Quick Decision Guide

| **Need**                    | **Use**       |
| --------------------------- | ------------- |
| Give AI new abilities       | **Tools**     |
| Load or display data in app | **Resources** |
| Let users trigger workflows | **Prompts**   |

> [!TIP]
> **Tools → serve the model**
> **Resources → serve the application**
> **Prompts → serve the user**
